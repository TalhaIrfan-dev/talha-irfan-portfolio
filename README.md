# Talha Irfan — Personal Portfolio

A responsive static portfolio built with plain HTML, CSS and JavaScript.

## Structure

```text
talha-irfan-portfolio-final/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── Talha-Irfan-CV.pdf
│   ├── images/
│   │   ├── talha-irfan.jpg
│   │   └── talha-irfan-original.jpg
│   ├── certificates/
│   │   └── arch-technologies-cpp-internship.png
│   ├── projects/
│   │   └── *.svg
│   └── icons/
│       └── favicon.svg
└── README.md
```

## Included

- Four theme system: Cyan Indigo, Warm Amber, Modern Blue, Light Warm Amber
- Compact theme palette in the navbar
- Responsive hero with provided portrait
- About section with journey timeline and four highlights
- Interactive skills overview that opens categorized details
- Filterable project grid with hover overlays and detail modals
- Arch Technologies internship section with certificate preview
- Education timeline/card + certification showcase
- Split contact section with developer terminal visual
- Minimal responsive footer
- CV download
- Local project illustrations so the site does not depend on external project screenshots

## Run locally

Open `index.html` directly, or use VS Code Live Server. No npm install is required.

## Notes

The page uses the supplied portrait, supplied Arch Technologies certificate and the public GitHub/LinkedIn information provided for the portfolio content. Some project thumbnails are intentionally stylized illustrations rather than screenshots; replace the SVG files in `assets/projects/` with real project screenshots later when desired.
